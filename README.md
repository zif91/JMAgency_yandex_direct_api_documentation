# Yandex Direct MCP Server

MCP сервер для работы с API Яндекс.Директ через удаленный сервис.

## Описание

Этот MCP сервер предоставляет доступ к функциям API Яндекс.Директ через удаленный прокси-сервер. Сервер позволяет получать информацию о кампаниях, группах объявлений, объявлениях, ключевых фразах и формировать отчеты.

## Установка

### Для использования в Jenova AI

1. Установите Python 3.10 или выше
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

### Конфигурация для Claude Desktop / Jenova AI

Добавьте в конфигурацию MCP серверов:

```json
{
  "mcpServers": {
    "yandex-direct": {
      "command": "python",
      "args": ["/path/to/server.py"],
      "env": {
        "DIRECT_API_URL": "https://direct.jmagency.ru",
        "DIRECT_API_KEY": "dk_988e363ce9a634c40c908a7d96af71305224d83c5b287e3c0a9b12a075411a85"
      }
    }
  }
}
```

Или используйте готовый npm пакет:

```json
{
  "mcpServers": {
    "yandex-direct": {
      "command": "npx",
      "args": ["-y", "@jacov911/direct-mcp-client"],
      "env": {
        "DIRECT_API_URL": "https://direct.jmagency.ru",
        "DIRECT_API_KEY": "dk_988e363ce9a634c40c908a7d96af71305224d83c5b287e3c0a9b12a075411a85"
      }
    }
  }
}
```

## Доступные инструменты

### 1. get_campaigns

Получить список всех рекламных кампаний.

**Пример использования:**
```
Получи список моих рекламных кампаний
```

### 2. get_adgroups

Получить группы объявлений для указанных кампаний.

**Параметры:**
- `campaign_ids` - массив ID кампаний

**Пример использования:**
```
Получи группы объявлений для кампании 12345
```

### 3. get_ads

Получить объявления для указанных групп объявлений.

**Параметры:**
- `adgroup_ids` - массив ID групп объявлений

**Пример использования:**
```
Получи объявления для групп 67890, 67891
```

### 4. get_keywords

Получить ключевые фразы для указанных групп объявлений.

**Параметры:**
- `adgroup_ids` - массив ID групп объявлений

**Пример использования:**
```
Получи ключевые слова для группы объявлений 67890
```

### 5. get_report

Сформировать и получить статистический отчет.

**Обязательные параметры:**
- `ReportName` - название отчета
- `ReportType` - тип отчета:
  - `CAMPAIGN_PERFORMANCE_REPORT` - статистика по кампаниям
  - `ADGROUP_PERFORMANCE_REPORT` - статистика по группам объявлений
  - `AD_PERFORMANCE_REPORT` - статистика по объявлениям
  - `CRITERIA_PERFORMANCE_REPORT` - статистика по условиям показа
  - `SEARCH_QUERY_PERFORMANCE_REPORT` - статистика по поисковым запросам
- `DateRangeType` - период:
  - `TODAY`, `YESTERDAY`
  - `LAST_7_DAYS`, `LAST_30_DAYS`, `LAST_90_DAYS`
  - `THIS_MONTH`, `LAST_MONTH`
  - `ALL_TIME`, `CUSTOM_DATE`
- `FieldNames` - список полей для отчета

**Доступные поля для отчетов:**
- `Date` - дата
- `CampaignName` - название кампании
- `CampaignId` - ID кампании
- `AdGroupName` - название группы объявлений
- `AdGroupId` - ID группы объявлений
- `Impressions` - показы
- `Clicks` - клики
- `Cost` - стоимость
- `Ctr` - CTR (кликабельность)
- `AvgCpc` - средняя стоимость клика
- `Conversions` - конверсии
- `Revenue` - доход

**Пример использования:**
```
Сформируй отчет по кампаниям за последние 7 дней с полями: дата, название кампании, показы, клики, стоимость
```

**Пример с фильтрами:**
```json
{
  "ReportName": "Campaign Report with Filter",
  "ReportType": "CAMPAIGN_PERFORMANCE_REPORT",
  "DateRangeType": "LAST_30_DAYS",
  "FieldNames": ["Date", "CampaignName", "Impressions", "Clicks", "Cost"],
  "SelectionCriteria": {
    "Filter": [
      {
        "Field": "Impressions",
        "Operator": "GREATER_THAN",
        "Values": ["100"]
      }
    ]
  }
}
```

## Примеры запросов

1. **Получить список кампаний:**
   ```
   Покажи мои рекламные кампании
   ```

2. **Получить статистику по кампаниям за неделю:**
   ```
   Создай отчет по всем кампаниям за последнюю неделю с показами, кликами и расходами
   ```

3. **Анализ эффективности ключевых фраз:**
   ```
   Покажи статистику по ключевым фразам для группы объявлений 123456 за последний месяц
   ```

## Переменные окружения

- `DIRECT_API_URL` - URL удаленного API (по умолчанию: https://direct.jmagency.ru)
- `DIRECT_API_KEY` - API ключ для аутентификации (обязательно)

## Запуск локально

```bash
# Установить переменные окружения
export DIRECT_API_URL="https://direct.jmagency.ru"
export DIRECT_API_KEY="your_api_key_here"

# Запустить сервер
python server.py
```

## Обработка ошибок

Сервер возвращает детальную информацию об ошибках:
- Ошибки HTTP статуса
- Ошибки API Яндекс.Директ
- Ошибки валидации параметров
