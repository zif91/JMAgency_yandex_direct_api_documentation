# Система баллов (Units)

[← Назад к оглавлению](../README.md)

## Обзор

API Яндекс Директа использует систему баллов (Units) для регулирования нагрузки на сервер. Каждый запрос расходует определённое количество баллов в зависимости от типа операции и объёма данных.

## Основные принципы

- Каждый рекламодатель/агентство имеет **индивидуальный суточный лимит**
- Лимит зависит от активности кампаний (показы, клики)
- Баллы восстанавливаются равномерно в течение суток
- Информация о баллах возвращается в заголовке `Units` каждого ответа

## Заголовок Units

Формат: `{потрачено}/{осталось}/{суточный_лимит}`

```http
Units: 10/20828/64000
```

| Значение | Описание |
|----------|----------|
| `10` | Потрачено на текущий запрос |
| `20828` | Осталось баллов |
| `64000` | Суточный лимит |

## Распределение баллов

### Временные интервалы

- Сутки делятся на **24 часовых интервала**
- В начале каждого интервала начисляется **1/24 суточного лимита**
- К новым баллам добавляются **неиспользованные баллы за последние 23 часа**
- Начало интервала **индивидуально** для каждого рекламодателя

### Пример расчёта

При суточном лимите 64 000 баллов:

```
Часовое пополнение = 64000 / 24 ≈ 2667 баллов
```

## Стоимость операций

### Стандартные стоимости

| Операция | Стоимость |
|----------|-----------|
| Успешный вызов метода | Базовая стоимость метода |
| За каждый возвращённый объект | 1 балл |
| Ошибка вызова метода | **20 баллов** |

## Использование баллов агентства

Агентства могут использовать собственные баллы вместо баллов клиента:

```http
Use-Operator-Units: true
```

### Когда использовать:

- При массовых операциях над клиентами
- Когда у клиента закончились баллы
- Для равномерного распределения нагрузки

## Мониторинг баллов

### Python-пример

```python
import requests

class YandexDirectClient:
    def __init__(self, token: str):
        self.token = token
        self.units_spent = 0
        self.units_remaining = 0
        self.units_daily_limit = 0

    def request(self, service: str, body: dict) -> dict:
        response = requests.post(
            f"https://api.direct.yandex.com/json/v5/{service}",
            json=body,
            headers={
                "Authorization": f"Bearer {self.token}",
                "Content-Type": "application/json"
            }
        )

        # Парсинг заголовка Units
        units = response.headers.get("Units", "")
        if units:
            parts = units.split("/")
            self.units_spent = int(parts[0])
            self.units_remaining = int(parts[1])
            self.units_daily_limit = int(parts[2])

        return response.json()

    def get_units_info(self) -> dict:
        return {
            "spent": self.units_spent,
            "remaining": self.units_remaining,
            "daily_limit": self.units_daily_limit,
            "usage_percent": round(
                (self.units_daily_limit - self.units_remaining) /
                self.units_daily_limit * 100, 2
            )
        }


# Использование
client = YandexDirectClient("YOUR_TOKEN")
result = client.request("campaigns", {
    "method": "get",
    "params": {"SelectionCriteria": {}, "FieldNames": ["Id"]}
})

info = client.get_units_info()
print(f"Использовано: {info['usage_percent']}% суточного лимита")
print(f"Осталось: {info['remaining']} из {info['daily_limit']}")
```

## Оптимизация расхода баллов

### Рекомендации

1. **Пакетные операции**
   - Группируйте однотипные операции в один запрос
   - Максимум объектов за запрос снижает базовую стоимость на объект

2. **Минимизация полей**
   - Запрашивайте только необходимые поля в `FieldNames`
   - Меньше данных = меньше баллов

3. **Эффективная пагинация**
   - Используйте максимальный `Limit` для уменьшения числа запросов
   - Кешируйте данные, которые редко меняются

4. **Избегайте ошибок**
   - Валидируйте данные перед отправкой
   - Ошибки дорого обходятся (20 баллов)

5. **Используйте Bids.set**
   - Этот метод бесплатный
   - Для массового обновления ставок — идеальный выбор

### Пример эффективного запроса

```python
# Неэффективно: 10 отдельных запросов
for campaign_id in campaign_ids:
    client.get_campaign(campaign_id)  # 10 × 15 = 150 баллов

# Эффективно: 1 пакетный запрос
client.get_campaigns(campaign_ids)  # 15 + 10 = 25 баллов
```

## Обработка исчерпания баллов

```python
import time

def request_with_retry(client, service, body, max_retries=3):
    for attempt in range(max_retries):
        result = client.request(service, body)

        if "error" in result:
            error_code = result["error"]["error_code"]

            # Код 152: Превышен лимит запросов
            if error_code == 152:
                wait_time = 60 * (attempt + 1)  # 1, 2, 3 минуты
                print(f"Баллы исчерпаны. Ожидание {wait_time} сек...")
                time.sleep(wait_time)
                continue

        return result

    raise Exception("Не удалось выполнить запрос после нескольких попыток")
```
