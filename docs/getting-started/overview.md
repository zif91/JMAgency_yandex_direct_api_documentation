# Обзор Yandex Direct API v5

[← Назад к оглавлению](../README.md)

## Что такое API Яндекс Директа

API Яндекс Директа — это программный интерфейс для автоматизированного управления рекламными кампаниями. Через API приложения могут:

- Создавать, редактировать и удалять кампании, группы объявлений, объявления и ключевые фразы
- Управлять ставками и бюджетами
- Получать статистику по показам, кликам, затратам и конверсиям
- Интегрироваться с CRM, BI-системами и внешними платформами

## Ключевые характеристики

| Параметр | Значение |
|----------|----------|
| Версия API | v5 (актуальная) |
| Протокол | HTTPS |
| Метод запросов | POST |
| Форматы данных | JSON (рекомендуемый), SOAP/XML |
| Авторизация | OAuth 2.0 |
| Стоимость | Бесплатно |

## Архитектура API

API состоит из модульных веб-сервисов, каждый из которых отвечает за работу с определённым типом объектов:

```
┌─────────────────────────────────────────────────────────────┐
│                     Yandex Direct API v5                     │
├─────────────┬─────────────┬─────────────┬──────────────────┤
│  Campaigns  │  AdGroups   │    Ads      │    Keywords      │
├─────────────┼─────────────┼─────────────┼──────────────────┤
│    Bids     │ BidModifiers│   Reports   │   Dictionaries   │
├─────────────┼─────────────┼─────────────┼──────────────────┤
│   Clients   │ AgencyClients│ Sitelinks  │     VCards       │
└─────────────┴─────────────┴─────────────┴──────────────────┘
```

## Базовые URL

### Production (боевой сервер)

```
JSON:  https://api.direct.yandex.com/json/v5/{service}
SOAP:  https://api.direct.yandex.com/v5/{service}
WSDL:  https://api.direct.yandex.com/v5/{service}?wsdl
```

### Sandbox (тестовый сервер)

```
JSON:  https://api-sandbox.direct.yandex.com/json/v5/{service}
SOAP:  https://api-sandbox.direct.yandex.com/v5/{service}
WSDL:  https://api-sandbox.direct.yandex.com/v5/{service}?wsdl
```

### Unified Performance Campaigns (v501)

Для работы с унифицированными перформанс-кампаниями используйте версию v501:

```
JSON:  https://api.direct.yandex.com/json/v501/{service}
SOAP:  https://api.direct.yandex.com/v501/{service}
```

## Стандартные методы сервисов

Большинство сервисов предоставляют стандартный набор методов:

| Метод | Описание |
|-------|----------|
| `add` | Создание новых объектов |
| `get` | Получение данных об объектах |
| `update` | Изменение существующих объектов |
| `delete` | Удаление объектов |
| `suspend` | Приостановка показов |
| `resume` | Возобновление показов |
| `archive` | Архивирование |
| `unarchive` | Разархивирование |

## Иерархия объектов

```
Account (Аккаунт рекламодателя)
│
├── Campaign (Кампания)
│   │
│   ├── AdGroup (Группа объявлений)
│   │   │
│   │   ├── Ad (Объявление)
│   │   │   ├── Sitelinks (Быстрые ссылки)
│   │   │   ├── VCard (Визитка)
│   │   │   └── AdExtensions (Расширения)
│   │   │
│   │   ├── Keyword (Ключевая фраза)
│   │   │   └── Bid (Ставка)
│   │   │
│   │   └── RetargetingList (Список ретаргетинга)
│   │
│   └── BidModifier (Корректировка ставок)
│
└── AdImage (Изображение)
```

## Типы кампаний

API поддерживает следующие типы кампаний:

| Тип | Описание |
|-----|----------|
| `TEXT_CAMPAIGN` | Текстово-графические объявления |
| `UNIFIED_CAMPAIGN` | Унифицированные перформанс-кампании |
| `SMART_CAMPAIGN` | Смарт-баннеры |
| `DYNAMIC_TEXT_CAMPAIGN` | Динамические объявления |
| `MOBILE_APP_CAMPAIGN` | Реклама мобильных приложений |
| `CPM_BANNER_CAMPAIGN` | Медийные кампании |
