# Регистрация приложения

[← Назад к оглавлению](../README.md)

## Обзор процесса

Для работы с API Яндекс Директа необходимо выполнить два этапа регистрации:

1. Регистрация приложения на Яндекс OAuth
2. Подача заявки на доступ к API Директа

## Этап 1: Регистрация на Яндекс OAuth

### Шаг 1.1: Создание приложения

1. Перейдите на страницу [создания приложения Яндекс OAuth](https://oauth.yandex.ru/client/new)
2. Авторизуйтесь под учётной записью разработчика
3. Выберите опцию **"Для доступа к API или отладки"**

### Шаг 1.2: Заполнение формы

Заполните обязательные поля:

| Поле | Описание |
|------|----------|
| **Название сервиса** | Произвольное название вашего приложения |
| **Контактная почта** | Email для связи по вопросам приложения |

### Шаг 1.3: Настройка доступа к данным

В разделе **"Доступ к данным"** добавьте следующие права:

- `passport:business` — Работа с организациями Яндекс ID
- `direct:api` — Использование API Яндекс Директа

### Шаг 1.4: Получение учётных данных

После создания приложения система сгенерирует:

- **ClientID** — идентификатор приложения
- **Client secret** — секретный ключ приложения

> **Важно:** Сохраните эти данные в безопасном месте. Client secret показывается только один раз.

## Этап 2: Заявка на доступ к API

### Шаг 2.1: Переход в настройки API

1. Войдите в [Яндекс Директ](https://direct.yandex.ru/)
2. Перейдите в раздел **"Настройки"** → **"API"**
3. Откройте вкладку **"Мои заявки"**

### Шаг 2.2: Выбор типа доступа

| Тип доступа | Описание | Ограничения |
|-------------|----------|-------------|
| **Тестовый доступ** | Для разработки и отладки | Только Песочница |
| **Полный доступ** | Для работы с реальными данными | Без ограничений |

### Шаг 2.3: Заполнение заявки

В форме заявки укажите:

1. **ClientID** — из этапа 1
2. **Описание приложения** — для чего будет использоваться API
3. **Контактные данные** — для связи по заявке

### Шаг 2.4: Ожидание одобрения

- Срок рассмотрения: **до 7 рабочих дней**
- Статусы заявки: `На рассмотрении` → `Одобрена` / `Отклонена`
- Уведомление придёт на указанный email

## Управление заявками

После подачи заявки вы можете:

- **Отслеживать статус** — в разделе "Мои заявки"
- **Редактировать заявку** — до момента рассмотрения
- **Преобразовать тестовый доступ в полный** — после одобрения тестового

## Требования к аккаунту

Для работы с API пользователь должен:

1. Иметь активный аккаунт в Яндекс Директе
2. Являться представителем бизнеса, агентства или клиентом агентства
3. Принять условия пользовательского соглашения API

## Права доступа

Права доступа через API определяются правами в веб-интерфейсе:

| Права в интерфейсе | Доступ через API |
|--------------------|------------------|
| Только чтение | Только методы `get` |
| Чтение и редактирование | Все методы |

## Безопасность

### Ограничение по IP-адресам

Для повышения безопасности рекомендуется указать список разрешённых IP-адресов:

1. Перейдите в **"Настройки API"** → **"Параметры"**
2. Добавьте IP-адреса серверов, с которых будут отправляться запросы

### Рекомендации

- Не передавайте Client secret третьим лицам
- Храните токены в защищённом хранилище
- Регулярно проверяйте активность приложения
- Используйте HTTPS для всех запросов
