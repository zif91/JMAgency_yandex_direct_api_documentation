How to Connect an Account

  1. Click "Add Account" button
  2. You'll be redirected to Yandex OAuth
  3. Login with your Yandex account and grant permissions
  4. The account will be added automatically

Account ID for API Calls

When making API calls, you can specify which account to use:

curl -X GET "http://localhost:5000/api/campaigns?account_id=YOUR_ACCOUNT_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"

If you don't specify an account_id, the first active account will be used.
