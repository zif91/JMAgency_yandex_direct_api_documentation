API Documentation

Use your API key to access campaigns programmatically:

Get Campaigns

curl -X GET http://localhost:5000/api/campaigns \
  -H "Authorization: Bearer YOUR_API_KEY"

Get Ad Groups

curl -X POST http://localhost:5000/api/adgroups \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"campaign_ids": [123456], "account_id": "optional-account-id"}'

Run Audit

curl -X POST http://localhost:5000/api/audit \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"account_id": "your-account-id", "audit_type": "full"}'

Get Report

curl -X POST http://localhost:5000/api/reports \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "account_id": "your-account-id",
    "ReportName": "Campaign Report",
    "ReportType": "CAMPAIGN_PERFORMANCE_REPORT",
    "DateRangeType": "LAST_7_DAYS",
    "Format": "TSV",
    "FieldNames": ["Date", "CampaignName", "Impressions", "Clicks", "Cost"]
  }'
