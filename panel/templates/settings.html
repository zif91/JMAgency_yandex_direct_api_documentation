API Usage Examples

Authentication

Include your API key in the Authorization header:

Authorization: Bearer {{ user.api_key[:20] }}...

Get All Connected Accounts

curl -X GET https://direct.jmagency.ru/api/accounts \
  -H "Authorization: Bearer YOUR_API_KEY"

Get Campaigns

curl -X GET "https://direct.jmagency.ru/api/campaigns?account_id=ACCOUNT_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"

Get Ad Groups

curl -X POST https://direct.jmagency.ru/api/adgroups \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "account_id": "YOUR_ACCOUNT_ID",
    "campaign_ids": [12345, 67890]
  }'

Get Keywords

curl -X POST https://direct.jmagency.ru/api/keywords \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "account_id": "YOUR_ACCOUNT_ID",
    "campaign_ids": [12345]
  }'

Run Audit via API

curl -X POST https://direct.jmagency.ru/api/audit \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "account_id": "YOUR_ACCOUNT_ID",
    "audit_type": "full"
  }'

Get Audit History

curl -X GET "https://direct.jmagency.ru/api/audit/history?limit=10" \
  -H "Authorization: Bearer YOUR_API_KEY"

Get Performance Report

curl -X POST https://direct.jmagency.ru/api/reports \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "account_id": "YOUR_ACCOUNT_ID",
    "ReportName": "Campaign Performance",
    "ReportType": "CAMPAIGN_PERFORMANCE_REPORT",
    "DateRangeType": "LAST_30_DAYS",
    "Format": "TSV",
    "IncludeVAT": "NO",
    "SelectionCriteria": {},
    "FieldNames": ["Date", "CampaignName", "Impressions", "Clicks", "Cost", "Conversions"]
  }'
